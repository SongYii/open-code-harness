# Judge 标签审查：真实校准前先建立可核对的证据链

**英文规范来源：** [Judge label review](2026-09-11-judge-label-review-design.md)。若有差异，以英文版为准。

**状态：** 已接受的规范设计

## 通俗说明

v3 有一道题只提供了“编辑成功、检查成功”，人却把它标成 Pass。DeepSeek 三次都认为
这不足以证明具体错字真的修好。已经揭晓后再改标签会破坏盲测，所以 v3 保持不动；
真正要修的是以后标签进入题库前的审查方式。

新题库声明 `labelReviewPolicy: evidence-v1` 后，每个标签都必须写出几条判断事实。每条
事实包含类型、解释、证据路径和证据中的逐字片段，还必须写明什么反例会改变标签。
程序会检查引用路径真实存在、原文确实包含该片段、所有证据角色都被查看，而且：

- Pass 必须同时有任务要求、完成事实和验证事实；
- Fail 必须有任务要求和违规事实；
- Indeterminate 必须有任务要求和无法定案的事实。

这不能让机器代替人的语义判断，但能让判断依据进入 Git、进入摘要、可以复核，也能
阻止“只有一句主观看法”的标签直接参与付费校准。v4 使用 12 道全新题，和 v1-v3
没有重名；两家服务的留出题及标签审查完全一致。
